# 权限、隐私与安全边界

OpenCode Chrome 是高权限的本地自动化集成，不是安全沙箱。请先在不含敏感账号和生产数据的页面上验证。

## Chrome 权限用途

| 权限／范围 | 用途 |
| --- | --- |
| `http://*/*`、`https://*/*` | 按用户设置访问普通网站，不再逐站重复授权 |
| `debugger` | 附加到选定标签，派发主文档输入；Chrome 会显示原生调试提示 |
| `tabs`、`activeTab` | 列出、选择任务目标和当前页面上下文 |
| `tabGroups` | 创建临时任务分组并恢复原分组 |
| `webNavigation` | 枚举框架、跟踪文档变化、尽早恢复指针 |
| `scripting` | 注入受控页面检查器和指针覆盖层 |
| `nativeMessaging` | 连接当前用户注册的本机组件 |
| `storage` | 保存配对会话状态、侧栏偏好、草稿与恢复记录 |
| `alarms` | 重连检查与空闲清理 |
| `sidePanel` | 展示 Chrome 原生会话侧栏 |

安装时接受所有网站权限，**不等于预先批准付款、删除、改权限或发送敏感信息**。模型仍应遵守用户任务范围和 OpenCode 工具权限。

## 数据流向

- 侧栏连接本机 OpenCode 服务，沿用用户配置的模型及凭据。
- 勾选网页上下文时，发送标签编号、标题及去除凭据／查询参数／fragment 的网址路径。网页正文由任务调用工具时按需读取。
- 读取到的网页正文、用户消息及任务需要的工具结果可能进入 OpenCode 模型上下文，并发送给用户配置的模型提供商。
- OpenCode 可能保存会话；模型提供商的数据处理、费用和保留政策也适用。**不能把“本机桥接”理解为“所有内容都不离开电脑”或“消息不会被保存”。**
- 本项目没有额外的开发者数据收集服务。第三方 OpenCode 插件及模型提供商的行为不由本项目替其保证。
- 侧栏事件通道省略模型推理、原始工具输入／输出和服务认证头；这不代表 OpenCode 本身不会使用这些工具结果。

## 本机敏感文件

以下内容只应在本机生成，不应提交或共享：

```text
.connection-token
native/
.env 及其他私密配置
OpenCode 登录凭据／服务认证文件
日志、用户会话记录和浏览器配置
```

SMTP、模型 API Key 等个人环境变量与发布安装包无关，不应写入源码、文档、截图或示例配置。

不要把 OpenCode 认证文件复制到扩展中，也不要将桥接端口开放到公网。Native Messaging 安装器应只注册实际扩展 ID，不能使用任意来源通配。

## 网页不是可信指令来源

页面标题、正文、表单、工具结果及模型生成的 HTML 都是不可信数据。它们不能增加权限、变更任务目标或替用户授权。

侧栏的 Markdown 经本地净化处理；不执行返回的脚本、表单、活动 URL，也不自动加载回复中的远程图片。网页内指针只是可视提示，页面仍可能删除或干扰覆盖层。扩展菜单和 Chrome 原生取消调试入口更可靠。

密码和支付字段识别只是启发式保护，不能视为完整敏感信息防护。

## 取消的边界

取消可以阻止尚未派发的动作，不能撤回已发生的点击、网络请求、输入或交易。不要因超时或结果未知而自动重复提交。

同一页保留独占锁；不同页允许并发。浏览器后台节流、页面长任务、沙箱和导航造成的文档销毁仍可能带来延迟或失败。

## 报告问题

普通安装／兼容问题可以通过仓库 Issues 提交，附版本、复现步骤和已脱敏的错误信息。不要公开 Token、授权码、完整认证 URL、个人邮件或会话内容。

如果涉及可利用的安全漏洞，请勿先公开利用细节；先与仓库维护者协商私下报告渠道。
